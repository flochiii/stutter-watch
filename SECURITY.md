# Security policy

Security fixes target the current `main` branch until versioned releases and a support policy are established.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/flochiii/stutter-watch/security/advisories/new). Include the affected commit, reproduction steps, impact, and a minimal proof of concept. Do not publish exploit details or sensitive recordings in an ordinary issue.

If the private form is unavailable, open a public issue asking the maintainer for a private contact without including vulnerability details. No response-time guarantee is currently offered.

## Diagnostic privacy

Window titles are disabled by default, but process names, PIDs, timing, hardware details, and driver names can still be sensitive. There is no automatic upload. Review files before sharing them. See [Data and privacy](docs/DATA_AND_PRIVACY.md).
