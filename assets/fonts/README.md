# Interface fonts

Both desktop versions use the same bundled fonts.

- **Ubuntu Light**: the unmodified `Ubuntu-Light.ttf` shipped with `epaint_default_fonts` 0.37.0. Copyright 2011 Canonical Ltd.; [Ubuntu Font Licence](UFL.txt).
- **Stutter Watch UI CJK SC / JP**: subsets of Noto Sans CJK under the [SIL Open Font License](OFL.txt). [Sources and reproduction](CJK.md).
