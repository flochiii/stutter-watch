The first **Windows x64 portable preview** of Stutter Watch.

### Download and run

Download **stutter-watch-0.1.0-windows-x64.zip**, extract the entire archive to a writable local folder, and open **stutter-watch.exe**. No installer or Rust toolchain is needed. The panel opens immediately; opening the app again activates the running monitor. Closing the panel keeps recording in the tray. Use **Quit** to stop it.

### Included

- Four charts with restored recent history: CPU/RAM, disk latency, Present API/window response, and DPC/ISR.
- Manual bookmarks with **Ctrl+Shift+F12**, automatic resource/delay signals, and protected incident captures.
- Local LZ4-compressed history, selectable sources, configurable tray metrics, and ten interface languages.
- English quick start, example configuration, build identity, complete target dependency notices, and a SHA-256 checksum file.
- A statically linked C runtime and GitHub build provenance for the archive.

### Before using it

This is an early preview. Windows 11 has been exercised locally; builds and isolated smoke tests run on Windows Server 2025 in GitHub Actions. Broader Windows 10 and driver coverage is still needed. Sources may need additional permissions or supported hardware. An incident is a diagnostic signal, not proof of the cause of a visible freeze. Linux and ARM64 builds are not included.

The executable is **unsigned**. GitHub provenance identifies the build workflow; it does not replace Windows code signing. Verify the archive against the matching `.sha256` file. With GitHub CLI installed, `gh attestation verify stutter-watch-0.1.0-windows-x64.zip --repo flochiii/stutter-watch` verifies provenance.

New configurations start in English with ordinary history limited to 500 MB / 24 hours. Protected captures are additional and kept until manually removed. Window titles are off by default, and no recordings are uploaded automatically. Review data before sharing it.
