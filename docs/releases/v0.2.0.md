# Stutter Watch v0.2.0

Windows installer and Linux desktop support, with local FPS recording import on both platforms.

## Downloads

| System | File | Use |
| --- | --- | --- |
| Windows x64 | `stutter-watch-0.2.0-windows-x64-setup.exe` | Per-user installation and controlled updates |
| Windows x64 | `stutter-watch-0.2.0-windows-x64.zip` | Portable, no installation |
| Debian / Ubuntu x64 | `stutter-watch_0.2.0_amd64.deb` | Install with apt |
| Fedora x64 | `stutter-watch-0.2.0-1.x86_64.rpm` | Install with dnf |
| Linux x64 | `stutter-watch-0.2.0-linux-x64.AppImage` | Portable desktop application |
| Linux x64 | `stutter-watch-0.2.0-linux-x64.tar.gz` | Manual installation / inspection |

Linux requires glibc 2.35+ and desktop graphics/keyboard libraries. See the [Linux guide](https://github.com/flochiii/stutter-watch/blob/main/docs/LINUX.md).

## Changes

- Separate Linux desktop and recorder processes; closing the window keeps recording and reopening restores recent charts.
- CPU, RAM, disk, process and pressure telemetry on Linux; guarded GPU collection, tray integration and platform shortcuts.
- Shared configuration, compressed history, protected bookmarks, automatic assessment and ten interface languages.
- Local MangoHud CSV import on Windows and Linux, with FPS/frame-time charts and an explicitly relative timeline.
- Windows setup preserves user configuration and recordings, waits for a running recorder to save, and supports rollback.

ETW Present/DPC/ISR and Win32 window probes remain Windows providers; Linux-specific pressure metrics have their own meaning. A highlighted resource signal is evidence to inspect, not a proven cause of a visible stutter. Hardware coverage and desktop integration depend on the driver, session and permissions.

## Verification and data

Each package has a SHA256 file and embedded `BUILD.json` source identity. Official build artifacts include GitHub provenance attestations and third-party notices. Windows binaries are unsigned. Removing the application preserves user configuration and recordings. No accounts, analytics or automatic log uploads are added.
